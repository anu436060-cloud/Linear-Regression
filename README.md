# Streamlit PDF Bot

An AI-powered chatbot that lets you upload PDFs and ask questions about their content. Built with Streamlit + Google Gemini API.

## Features
- Upload any PDF and chat with it instantly
- Ask questions in plain English, get answers pulled from the document
- Clean Streamlit interface, runs locally or on Streamlit Cloud

## Tech Stack
- **Frontend**: Streamlit
- **LLM**: Google Gemini API
- **PDF Parsing**: PyPDF2 / pdfplumber
- **Language**: Python
